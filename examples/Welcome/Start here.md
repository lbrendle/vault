## A gentler workflow

Keep the source. Write down what you noticed. Separate an observation from an explanation. Leave a link for your future self.

| Practice | A small beginning |
| --- | --- |
| Observe | Write one precise sentence |
| Connect | Link to a nearby idea |
| Question | Name what you do not know |
| Return | Revisit a note tomorrow |

Your folder remains yours. Take it with you.
