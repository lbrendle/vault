# Community expectations

Be kind, specific, and constructive. Respect different experience levels. Critique behavior and code rather than people. Harassment, threats, discriminatory abuse, sexualized attention, doxxing, and publication of another person's private information are not welcome.

These expectations apply in project issues, discussions, pull requests, and other spaces maintained by the project. Maintainers may edit or remove harmful content and temporarily or permanently restrict participation, with a proportionate explanation where safe.

To report a concern privately, use the repository's private reporting channel described in SECURITY.md and state that it concerns conduct. Avoid repeating private information in public threads. Maintainers should handle reports discreetly, consider context, and apply these expectations consistently.
